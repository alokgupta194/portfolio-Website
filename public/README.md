# Alok Gupta Portfolio

Simple static portfolio built with:
- HTML
- CSS
- Vanilla JavaScript

## Files
- index.html
- style.css
- index.js

## Run
Open `index.html` directly in a browser, or upload all three files to Netlify, Vercel, GitHub Pages, or any static hosting.

## Customize
Most portfolio content is stored at the top of `index.js` inside the `portfolio` object.
